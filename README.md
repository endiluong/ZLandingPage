# Room Tour

A scroll-guided three.js tour of my room and working space. Every object is built in code.

```
npm install
npm run dev
```

- `src/room.js`: the room and its objects (currently a placeholder room)
- `src/tour.js`: camera stops, one per `<section>` in `index.html`
- `src/lighting.js`: morning / day / evening / night presets
